DIGITAL ELECTRONICS

Build it bit by bit.

Digital electronics is the study of circuits that process information using discrete signals, usually represented as 0 and 1. These signals power computers, phones, controllers and every modern digital device.

Start with a foundation

Numbers are the first language of a circuit.

Before a circuit can calculate, store or communicate, it needs a reliable way to represent values. Number systems translate those values into patterns of bits that digital hardware can understand.

Digital electronics A branch of electronics that works with discrete signal levels to represent, process and move information.

Quick reference

Term definitions

DecimalBase-10 system using digits 0 through 9.
BinaryBase-2 system using only 0 and 1, the language of digital circuits.
OctalBase-8 system using digits 0 through 7. Each octal digit represents three binary bits.
HexadecimalBase-16 system using 0 through 9 and A through F. Each digit represents four bits.
BCD (8421)Binary Coded Decimal: each decimal digit is stored separately as a four-bit group.
Gray CodeA binary code where adjacent values differ by exactly one bit.
1's ComplementFound by changing every 0 to 1 and every 1 to 0 in a fixed-width binary value.
2's ComplementFound by taking the 1's complement and adding 1; commonly used to represent signed integers.
