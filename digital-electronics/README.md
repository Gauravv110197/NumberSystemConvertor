# Digital Electronics

A static number-system learning tool by Gaurav Singh.

## Files

- `index.html` - page structure and content
- `styles.css` - layout, responsive design, and popup styling
- `script.js` - number conversions and working steps

## Run locally

Open `index.html` in a browser.

## Deploy with Vercel

1. Upload the `digital-electronics` folder to your repository.
2. In Vercel, import the repository.
3. Set the Root Directory to `digital-electronics`.
4. Leave Framework Preset as `Other`.
5. Deploy.

No build command or environment variables are required.
